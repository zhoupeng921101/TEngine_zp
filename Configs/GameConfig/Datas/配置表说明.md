# 配置表说明

本工程全部游戏配置表(Luban 数据表)的字段说明,供策划编辑数值时查阅。

## 基本约定

- **源文件**:本目录(`Configs/GameConfig/Datas/`)下的 `.xlsx` 是唯一编辑入口。结构(表/字段/枚举/Bean)定义在 `__tables__.xlsx` / `__beans__.xlsx` / `__enums__.xlsx`。
- **改完必须导表**:xlsx 是源,运行时读的是 Luban 导出的二进制 `.bytes`(客户端 `UnityProject/Assets/AssetRaw/Configs/bytes/`、服务端 `Fantasy/.../GameConfigBytes/` 各一份)。手改 xlsx 后不导表不生效。
- **双端共用**:客户端(Unity)与 Fantasy 服务端读同一份导出 `.bytes`,改一处数值两端同步。凡玩家资源/进度/奖励发放由**服务端权威裁定**,客户端只做显示;改数值改这里,发放逻辑在服务端。
- **文本 id**:字段标「文本id」者存的是多语言表主键,不是字面串;实际显示文案在多语言表按 id 取。
- **图标/资源名**:字段标「资源名/路径」者存的是资源定位名,对应美术产出的图集子图名或资源文件名。

## 配置表一览

| 表 | 源文件 | 主键 / 组织 | 用途 |
|---|---|---|---|
| TbGlobal | `global.xlsx` | id 键值映射 | 全局零散参数(键值型,业务按需解析) |
| TbNum | `num.xlsx` | id 映射 | 数值底层货币定义(经验/虔诚/钻石/体力) |
| TbItemDef | `itemdef.xlsx` | id 映射 | 道具定义(背包物品/礼包/材料) |
| TbGiftRandom | `giftrandom.xlsx` | auto_id 行主键,index 分池 | 随机礼包奖池(按权重抽) |
| TbGiftSelect | `giftselect.xlsx` | auto_id 行主键,index 分池 | 自选礼包奖池(玩家选) |
| TbAvatar | `avatar.xlsx` | id 映射 | 头像与头像框 |
| TbMail | `mail.xlsx` | id 映射 | 邮件模板 |
| TbMailGlobal | `mail_global.xlsx` | 单行(id=1) | 邮件系统全局参数 |
| TbRank | `rank.xlsx` | row_id 行主键,id 可重复(多档) | 排行榜档位定义 |
| TbMergeOrder | `merge_order.xlsx` | id 映射(池序=id 升序) | 订单池(需求 + 交付奖励) |
| TbTarotCard | `tarot_card.xlsx` | id 映射(1-22 大阿卡纳) | 塔罗牌收集图鉴 |
| TbAudio | `audio.xlsx` | id 映射 | 音频资源与播放参数 |
| TbGoddessReward | `goddess_reward.xlsx` | 当前单档 | 女神满档清屏领取奖励 |
| TbWeightCfg | `weightcfg.xlsx` | id 映射(动态权重 tier) | 方块玩法动态难度权重 |

## TbGlobal — 全局参数

键值型:每行一个参数,`value` 统一以字符串存,业务侧按需解析为 int/float/bool。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 参数 id |
| value | string | 参数值(按需解析) |

现用参数 id(与业务约定一致):

| id | 含义 |
|---|---|
| 1 | 订单数量(同时可接订单上限) |
| 2 | 订单刷新时间(秒) |
| 3 | 体力恢复("点数#间隔秒",如 `1#360`;兼容旧 bare int 作间隔) |
| 4 | 体力恢复上限 |
| 5 | 消除道具(清行列)消耗体力 |
| 6 | 音频全局默认防连点时间(秒) |
| 7 | 女神满档清屏次数(积攒全清到此值可领一次,可循环) |

## TbNum — 数值货币定义

底层数值资源(货币类)的元数据。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 资源 id |
| desc | int | 描述文本 id |
| name | int | 名称文本 id |
| icon | string | 图标资源名 |
| numType | enum ENumType | 资源类型 |
| quality | int | 数值品质 |

**ENumType**:1=经验 EXP,2=虔诚币 PIETY,3=钻石 DIAMOND,4=体力 ENERGY。

## TbItemDef — 道具定义

背包物品/礼包/材料的完整定义。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 道具唯一 id(主键) |
| name | int | 道具名(文本 id) |
| desc | int | 道具描述(文本 id) |
| icon | string | 图标资源名 |
| quality | enum EItemQuality | 品质(1-6) |
| light | string | icon 特效 id/路径 |
| automatic | int | 获得时是否自动使用(0 否 1 是) |
| type | enum EItemType | 道具类型(背包归类) |
| param | int | 参数:自选/随机礼包奖励数量或开启次数 |
| useEffect | int | 使用效果:0 无 / 1 num / 2 图案 / 3 自选礼包 id / 4 随机礼包 id |
| useValue | int | 使用效果目标 id(随 useEffect 语义:1→num_id / 2→图案 key / 3→自选 index / 4→随机 index) |
| useNum | int | 使用效果数量(1→货币数量 / 2→图案数量) |
| useLevel | int | 图案等级(useEffect=2 时 1-3,其余 0) |
| stacking | int | 可叠放(0 否 1 是;上限 999) |
| term | int | 限时(0 非限时 / 1 指定日期 / 2 指定时长) |
| termPrompt | int | 限时提示(文本 id) |
| termTime | string | 限时时间(日期串 / 时长秒) |
| compensate | int | 到期补偿(Reward 表 id) |
| compensateEmail | int | 补偿邮件(邮件 id) |
| jumpList | int[] | 获取跳转列表 |

**EItemQuality**:1=普通 COMMON,2=高级 FINE,3=精英 ELITE,4=史诗 EPIC,5=传说 LEGEND,6=神话 MYTH。
**EItemType**:1=货币 CURRENCY,2=材料 MATERIAL,3=功能材料 FUNC_MATERIAL,5=自选礼包 GIFT_SELECT,6=随机礼包 GIFT_RANDOM(无 4)。

## TbGiftRandom — 随机礼包奖池

同 `index` 的所有行构成一个奖池,按 `rate` 权重随机抽取。

| 字段 | 类型 | 说明 |
|---|---|---|
| autoId | int | 行主键(index=auto_id) |
| index | int | 所属礼包 id(同 index = 一个奖池) |
| itemId | int | 奖品道具 id(指向 TbItemDef) |
| num | int | 该奖品数量 |
| rate | int | 权重(抽中概率 = rate / 同 index 全部 rate 之和) |

---

## TbGiftSelect — 自选礼包奖池

结构同随机礼包,区别在玩家从同 `index` 池中手动选取而非随机。

| 字段 | 类型 | 说明 |
|---|---|---|
| autoId | int | 行主键(index=auto_id) |
| index | int | 所属礼包 id(同 index = 一个奖池) |
| itemId | int | 奖品道具 id(指向 TbItemDef) |
| num | int | 该奖品数量 |
| rate | int | 权重(自选场景一般用于展示排序/概率提示) |

| 字段 | 类型 | 说明 |

| id | int | 榜 id(可重复=多档) |
| name | int | 名称文本 id |
| rankGroup | int | 榜分组 |
| rankMethod | int | 玩法方式 |

| rankMin | int | 名次下限(含) |
| rankMax | int | 名次上限(含) |

## TbMergeOrder — 订单池

池序 = id 升序,游标按池长取模循环。每行 = 一个订单:前段是需求,后段是交付奖励。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 订单池行号(池序=id 升序) |
| elementType | int | 元素类型(=客户端 MergeElement;1 蝶 2 杯 3 卷 4 星) |
| level | int | 元素等级(1-5) |
| count | int | 需求数量 |
| energyReward | int | 交付奖励体力 |
| pietyReward | int | 交付奖励虔诚币 |
| fragmentItemId | int | 掉落塔罗碎片道具 id(=TbItemDef 行) |
| fragmentCount | int | 掉落碎片数量 |

## TbTarotCard — 塔罗牌图鉴

|---|---|---|

| name | string | 牌名(图鉴显示) |
| icon | string | 牌面图标资源名 |
| fragmentItemId | int | 对应碎片道具 id(=TbItemDef 行) |
| fragmentsNeeded | int | 合成所需碎片数 |

## TbAudio — 音频配置

数据驱动播放:业务按 id 播放,音量/循环/防连点/淡入淡出/混音分组由本表控制。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 音频唯一 id(主键) |
| type | enum EAudioType | 粗分类 |
| resourcePath | string | AudioClip 资源路径 |
| volume | float | 基础音量(0~1) |
| loop | bool | 是否循环 |
| cooldown | float | 专属防连点秒(0=用全局 DefaultCooldown) |
| interruptible | bool | 是否可被同通道高权重音效打断 |
| fadeInOut | enum EAudioFade | 淡入淡出模式 |
| audioGroup | enum EAudioGroup | 混音分组(type 的子类型) |

**EAudioType**:0=背景音乐 BGM,1=全局 UI 音效 GlobalUI,2=局内玩法音效 InGame。
**EAudioFade**:0=无 None,1=仅淡入 In,2=仅淡出 Out,3=双向 Both。
**EAudioGroup**:0=全局 Global,1=背景音乐 BGM,2=界面 UI,3=战斗 Battle,4=语音 Voice。

## TbGoddessReward — 女神满档奖励

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 行主键(女神奖励档) |
| level | int | 发放元素等级(1-5) |
| count | int | 发放数量 |

---

## TbWeightCfg — 动态难度权重

方块玩法按分数区间(highScoreMin~highScoreMax)选 tier,tier 内各出块算法按权重随机。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | int | 动态权重 tier id |
| fillBlankOdds | int | 填空消除算法权重 |
| randomOdds | int | 随机无死亡算法权重 |
| entropyOdds | int | 熵增算法权重 |
| easyOdds | int | 简单难题权重 |
| hardOdds | int | 困难难题权重 |
| intuitionOdds | int | 直觉死亡难题权重 |
| clearboard | int | 清盘 Plus 权重 |
| allunite | int | 全组合填空消除权重 |
| highScoreMin | int | 分数下限 |
| highScoreMax | int | 分数上限(-1 无上限) |
| factorLow | int | 系数区间下界 |
| factorHigh | int | 系数区间上界 |
