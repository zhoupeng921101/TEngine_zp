设计稿正文用简洁说明文,避「钉死/焊死/绑死」一类「X死」拟人比喻(conventions 规则5「语体」;收尾 `grep -nE '钉死|焊死|绑死|打死|死在'` 自检,改「明确/确定/耦合」)——「短路」(控制流)「爆栈」(stack overflow)是行业术语,合法照用。

**Why:** 拟人比喻看似省字、实际只对共享比喻的圈内读者清晰,会顺上下文漏进对用户的呈报(2026-06 实测 20 收尾「焊死/钉死」漏进正文)。

**How to apply:** 写完设计稿收尾跑 `grep -nE '钉死|焊死|绑死|打死|死在'` 自检,命中改「明确/确定/耦合」等中性词;行业术语(短路、爆栈、回归、热更)不算比喻、照用。
