整篇重写设计稿(脱离过时叙事/时态)前,先 grep 全库列**入站引用的两件东西**:`file.html#id`(锚 id)+ 可见章节号文字(`10·§2.3`/`09·§四`)。他篇同时靠这两者跳转/指路——光保 id 不够,删/挪节会移位可见章节号,使「10·§四」文字虽落对 anchor 却显示错号。

对策:**保章节号不移位**——要删的节改写成现状内容占位(保其 id + 编号)而非整体删除致后续节上移(本例 10 删「移除收集」②,把 §三 改写成「依赖的元素设施」现状,保 #remove/#removed/#keep/#misnomer 四 id + §四=hook 编号,护住「10·§四」「10·§2.3」全部入站引用);真要改编号则同任务同步改全部他篇可见引用文字。

另:重写须连带清「他篇指向本篇过时锚的引用」——本例 10 原 §2.1 把已删 InjectChance 当现状指 `09·§七`,重写后该出站锚消失=硬矛盾自然解除。

**Why:** 2026-06 09/10 整篇重写实践:可见章节号也是入站契约,光保 anchor id 不够。

**How to apply:** 整篇重写前 grep `<file>.html#` 和 `<file>·§` 两路;改完连带搜本篇出站锚是否还存在,清孤儿引用。
