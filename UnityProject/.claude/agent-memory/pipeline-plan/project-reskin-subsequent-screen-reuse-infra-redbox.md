第 N 个换皮屏复用第 1 屏已打通的换皮基础设施时:简报常已点明「复用 X 范式不要重造」,落实=设计稿篇首立「基础设施全部复用设计 N、无新基础设施」红框 + 逐项指到已打通的章节(切图寻址/绑定/窗口范式/运行期上下文),正文只写本屏差异(节点树对位新效果图、数据服务换成本屏的、缺图占位策略)。

GameContext 类「后续系统逐个挂入」的预告由后续屏逐个兑现(本例 player-info 项),加成员而非另套单例。

**Why:** 2026-06 player-info 窗复用 23 设置窗范式 + 兑现 GameContext.Player 挂入预告先例。

**How to apply:** 后续屏稿篇首红框 + 逐项指基础设施章节;正文只写本屏差异;GameContext 加成员复用,不另设单例。
