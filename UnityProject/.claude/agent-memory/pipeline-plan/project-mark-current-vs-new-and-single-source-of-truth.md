完整设计含大量未落地系统时,每节标注「现状/本篇新增」+ 篇首立「单一事实源=代码」红框 + 每个新系统给「可降级到 demo 范围」说明——防 dev 误把设计目标当现状改坏切片,且便于 boss 按需切片分批落地。

**Why:** 完整设计稿同时含已落地和未落地两类内容,不标会让 dev 误改已落地切片去拼未落地目标(2026-06 11 核心补全先例)。

**How to apply:** 写整体规划稿时每节加「现状/本篇新增」标签,篇首立红框声明代码是单一事实源;每个未落地系统给最小可降级版本说明,供 boss 分批切。
