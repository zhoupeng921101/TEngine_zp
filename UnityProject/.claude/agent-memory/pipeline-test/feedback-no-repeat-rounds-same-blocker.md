同一未注册实例跨轮复跑徒劳:首轮已做全量静态核验且代码零改动时,后续轮只需确认阻塞仍在 + 刷新诊断,不重复逐例手推(无新信息)。

**Why:** 2026-06 实测,阻塞未解、代码未动的情况下,逐例手工复跑只会产出与首轮相同的报告,既不证伪也不带新证据,纯粹浪费上下文。

**How to apply:** 复测前先比对 git diff 是否有真实代码改动;无改动且环境阻塞仍在 → 只确认阻塞依旧(短报告)+ 刷新诊断信号(进程状态/连接状态),不重跑全套静态用例。
