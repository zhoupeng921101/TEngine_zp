  type: feedback

返修轮复验聚焦三点:① CR 逐点静态核验(改动是否符合返修简报的闭合说明)、② 重跑编译确认 0 error 0 warning、③ 确认返修未触碰已 PASS 的其他路径。其余已 PASS 项(源生成器/协议同步/其他 SV)沿用上轮结论,不从头重审。

**Why:** 返修轮若全量重审,等于重复上轮工作且结论相同,浪费往返;聚焦 CR + 回归是最小充分集合。

**How to apply:** 返修轮开工先读上轮 FAIL 的可复现清单 + 本轮返修交接区,仅针对 CR 闭合做逐点核验;对无改动文件仅确认「未被触碰」即可引用上轮结论。
