# clip 切图资产清单

本目录为 `Atlas_blocks_clip` 图集的源切图,塔罗主题元素图标,带透明通道。供拼装 UI 时按语义挑选。

寻址:打包进 `Atlas_blocks_clip` 图集后,以下方「sprite 名」(即文件名去扩展名)取图。

命名规则:`类别_特征`,全小写下划线。同类元素按「颜色 / 是否镶嵌宝石 / 华丽度」区分档位,可作同一元素的不同皮肤等级。
