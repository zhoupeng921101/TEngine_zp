# blocks_skin 方块皮肤资产清单

本目录为 `Atlas_blocks_blocks_skin` 图集的源切图，全部为方形方块贴图，用于游戏棋盘格的方块外观。

寻址：打包进 `Atlas_blocks_blocks_skin` 后，以 `blocks_skin_atlas_<编号>` 为 sprite 名取图。

## 总览

| 属性 | 值 |
|------|-----|
| 总数 | 337 张 |
| 主尺寸 | 84×84 px（331 张） |
| 小尺寸 | 44×44 px（6 张，见下） |
| 图集名 | `Atlas_blocks_blocks_skin` |

## 使用建议

**拼界面时挑色方案：** 每个编号段内颜色排列顺序基本固定（同段内相邻编号 = 同纹理的不同颜色）。拼某一主题界面时，从同一编号段内选取多个相邻编号，可获得风格一致的色组。

**快速找某颜色：** 从各段起始编号（7、29、51、226）向后偏移少量步长即可覆盖大部分色彩。若需宝石质感首选 51-97 或 226-477 段；若需平面扁平风，7-47 段更多。

**不要跨段混用：** 不同段的纹理风格差异明显，同屏方块应保持同一编号段内取图，避免视觉不统一。
