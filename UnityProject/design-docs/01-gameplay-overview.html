玩法总览

现状分析 · 一句话：8×8 拖放消除无尽模式，得分靠「憋大招多行列同消」，真正的核心是一套会偷偷调整发牌难易的动态难度系统，让你总觉得「就差一点」。

本文档基于代码现状整理，对应模块：Assets/GameScripts/HotFix/GameLogic/Module/BlockBlast/。目前仅 Classic（无尽）模式，无关卡 / 冒险 / 收集。

一、核心玩法循环

经典 8×8 棋盘 + 三块拖放消除（同类：Block Blast / 1010!）。每回合流程：

  1. 手上有 3 个候选方块（OperaArr[3]）。
  2. 拖拽方块到棋盘空位落子，落点合法才放得下；拖动时有 ghost 预览（绿色可放 / 红色不可放）。
  3. 落子后检测整行 / 整列填满 → 消除。
  4. 三块全部用完 → 补满下一组 3 块。
  5. 剩余手牌无任何合法落点 → Game Over。

三窗口流转：主菜单 MainMenuWindow → 游戏 GameWindow → 结算 GameOverWindow。

二、得分规则

行为得分公式说明
落子每格 +1方块占几格加几分
消除消除格数 × 10 + 行列数² × 30同时消越多行列，奖励呈平方级暴涨

消除收益示例（平方奖励鼓励「憋大招」）：

同时消除行列数²×30体感
1 行/列+30常规
2 行/列+120值得等
3 行/列+270大爽点
注意（潜在设计点）： 代码里有 Combo 连击计数（连续落子都有消除则 +1，断了清零），但 Combo 目前没有进入任何得分公式——是一个已埋好但未启用的爽点钩子。

三、方块库

  • 共 71 种形状定义，实际抽取池为 39 种 COMMON。
  • 新手首发固定 [9, 39, 24]（2×2 方块、L 形、大 L），保证开局好上手。
  • 早期屏蔽：分数 < 10000 时，剔除特别难放的大形状（EarlyGameBlockedIds），降低前期挫败。

四、最大特色：动态难度调度

这是本作区别于普通方块消除的灵魂——发牌不是纯随机，而是根据玩家表现「做局」（一套橡皮筋式动态难度 DDA）。分数段决定调度策略：

分数段调度行为
< 1000纯随机无死亡，保证开局不卡
1000 ~ 15000清屏窗口：系统用贪心算法主动喂「能清空棋盘」的方块，引导清盘；清空后冷却 1~2 回合走普通调度，再开窗口（张弛节奏）
≥ 1000 激活动态权重：8 种算法按权重抽取发牌

8 种发牌算法（从「放水」到「做死」）

算法倾向
Fill / ClearAll / AllCombination放水 好放、好消、助清盘
RandomNoDie / EasyDiff中性偏易
Add3（熵增）/ Diff（困难）/ StraightDeathDiff（死亡难题）做局 故意给难放 / 逼死的方块

核心变量 dynamicWeight：玩家放了「难」方块权重下降、放「易」方块权重上升，系统据此在不同 tier（难度档）间切换发牌策略，让玩家长期停在「差点死又没死」的心流区。权重配置走 Luban 表 weightcfg。

这套系统是本作的灵魂，单独拆成一篇详解（含 8 种算法逐一拆解 + 真实权重数据）：→ 动态难度拆解。

五、其它

  • 存档：棋盘 + 手牌 + 分数 + 最高分本地持久化，支持断线续玩。
  • UI：纯几何 UGUI 代码绘制（无美术 prefab），有分数滚动动画。
